Chitu 2 HD Custom, Stand chitu-CRd (Firmware für den Mobapad Chitu 2 HD) – EXPERIMENTELL

jl_isd.bin          Erstinstallation von der Werks-Firmware, nur über das USB-Kabel:
                    c2lite-custom installieren release/chitu/jl_isd.bin --usb
                    (Kabel ab, Chitu ohne Kabel mit Home einschalten, Kabel anstecken, beim Brummen Home + Y + X halten)
db_update_data.bin  Update, wenn die eigene Firmware schon läuft: c2lite-custom update release/chitu/db_update_data.bin
SHA256SUMS          Prüfsummen: sha256sum -c SHA256SUMS

Das Werkzeug prüft vor dem Schreiben, ob Firmware und Controller zusammenpassen (Chitu-Firmware nie auf den C2 Lite
und umgekehrt). Rückweg zur Werks-Firmware: c2lite-custom werk-zurueck <Sicherung aus ~/c2lite-sicherung>.
Vorher den Abschnitt „Chitu 2 HD“ und „Risiken“ in der README lesen. Nutzung auf eigenes Risiko.

English: EXPERIMENTAL firmware for the Mobapad Chitu 2 HD. jl_isd.bin = first install from the factory firmware over
USB only (`c2lite-custom installieren release/chitu/jl_isd.bin --usb`: unplug, switch on with Home, plug in, hold
Home + Y + X while it rumbles); db_update_data.bin = update (`c2lite-custom update release/chitu/db_update_data.bin`).
The tool refuses to write firmware meant for the other controller. Way back: `c2lite-custom werk-zurueck <backup>`.
Check with `sha256sum -c SHA256SUMS`. Read the "Chitu 2 HD" and "Risks" sections in the README first. Use at your own risk.
